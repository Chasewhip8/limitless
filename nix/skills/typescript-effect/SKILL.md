# TypeScript-Effect

High-quality Effect TypeScript reference material is available through the globally installed `effect-solutions` CLI.

## When to Use

- Working with the Effect library in TypeScript code
- Adding or refactoring Effect services, layers, schemas, configuration, CLI commands, or tests
- Looking for Effect examples, topic references, or implementation patterns
- Debugging unfamiliar Effect APIs, runtime behavior, typed errors, or resource lifecycles
- Checking project setup or TypeScript configuration guidance for Effect

## Core Commands

- `effect-solutions list` - list available guides and topic names.
- `effect-solutions show <topic>` - show one guide or topic.
- `effect-solutions show <topic> <topic> ...` - show multiple related topics in one call.

Useful starting points:

- `effect-solutions show quick-start`
- `effect-solutions show project-setup tsconfig`
- `effect-solutions show services-and-layers error-handling testing`
- `effect-solutions show config data-modeling cli`
